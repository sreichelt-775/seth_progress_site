Tank-scale tests

Plots and notes for the first ~3200 hours pulled on 2026-06-06.

Update summary

The plots below show the most up-to-date tank dataset through ~3200 hours, pulled on 6/06. The volumetric water content is still showing a steady decline at the 50 mm from-heater location. I think it could be a good time to increase the heater temperature by swapping the thermocouples. This would allow me to begin hydration after we see further steady trends in the moisture distribution. Ideally, I would like to start hydration this summer, when I can monitor the pumps throughout the day without interruption.

There is a large drop in the thermocouple reading placed at the bottom of the tank, as seen in the temperature plot around 2950 hours. This is clearly an acquisition error, and I am hoping it corrects itself. For now, I am planning to add a step function to remove this vertical spike. All of the external wiring is intact, so if this error is physical due to thermal or mechanical stress on the thermocouple inside the tank, I will leave the step function in place for the remainder of the test.

Vertical strain / LVDT correction

Manual voltage-to-displacement correction, stacked data, and filtered vertical strain plots.

Update summary

The plots below show the vertical strain processing after revisiting the earlier LVDT data and manually correcting the voltage-to-displacement conversion using two different zero values for the two time periods in which the LVDT position had changed.

The original corrected data still contained many obvious spikes and abrupt jumps that did not appear physically realistic, so I applied filtering, smoothing, and a de-stepping correction to remove the strongest voltage- and noise-related artifacts before stacking it with the newer cleaned data pulls. The newer data should remain more consistent moving forward because I will no longer be moving the LVDT.

Even though Yu’s vertical strain plot was smoother during this same initial heating portion, the strain changes in my data are still generally under about 0.2%, which is negligible relative to the 207.5 mm layer height. Any remaining roughness should be minor once plotted at full scale and compared with the larger changes expected later during hydration.
